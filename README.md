# ATmega4809 Curiosity Nano Resources

This repository contains reference documents, datasheets, pinout information,
schematics, user guides, and hardware design resources for the
**ATmega4809 Curiosity Nano Development Board**.

These files are useful for learning, circuit design, embedded programming,
hardware development, and PCB design using the ATmega4809 microcontroller.

---

## Contents

The repository includes the following resources:

### 1. ATmega4809 Curiosity Nano Altium Project

Altium Designer project files for the ATmega4809 Curiosity Nano board.

This folder contains the original hardware design resources, including
schematic and PCB-related project files.

### 2. ATmega4809 Curiosity Nano Pinout

Reference document showing the pin configuration of the
ATmega4809 Curiosity Nano board.

It can be used to identify:

- GPIO pins
- Power pins
- Ground pins
- Analog pins
- Digital communication pins
- UART pins
- SPI pins
- I2C pins
- Programming and debugging pins

### 3. ATmega4809 Curiosity Nano Schematics

Complete circuit schematic of the ATmega4809 Curiosity Nano development board.

The schematic helps in understanding:

- ATmega4809 connections
- Power supply circuit
- USB interface
- Programming and debugging interface
- Clock circuit
- Reset circuit
- LED connections
- Connector pin connections

### 4. ATmega4809 Datasheet

Official technical reference document for the ATmega4809 microcontroller.

The datasheet contains information about:

- Microcontroller architecture
- Pin configuration
- Electrical characteristics
- GPIO operation
- Timers and counters
- ADC
- USART
- SPI
- TWI/I2C
- Interrupts
- Memory organization
- Clock system
- Power management
- Register descriptions

### 5. ATmega4809 Curiosity Nano User Guide

User guide for the ATmega4809 Curiosity Nano development board.

It provides information about:

- Board features
- Hardware configuration
- Power supply
- Programming
- Debugging
- USB connection
- Board operation
- Connector details

### 6. ATmega4809 Curiosity Nano Pinout

Additional pinout reference for quickly identifying the board connections
and corresponding ATmega4809 pins.

### 7. ATmega4809 Curiosity Nano Schematics

Additional schematic reference for studying the complete hardware design
of the development board.

### 8. Curiosity Nano Explorer User Guide - DS50003716

User guide for the Curiosity Nano Explorer platform.

This document explains the Curiosity Nano development environment and
related hardware features.

### 9. Curiosity Nano Explorer Schematics

Schematic reference for the Curiosity Nano Explorer hardware.

It can be used to understand the connections between the Curiosity Nano
board and the Explorer platform.
